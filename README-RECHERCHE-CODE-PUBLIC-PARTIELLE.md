# Recherche partielle du code public

La recherche accepte maintenant explicitement les fragments du code public actuel (`SUB-0005`), notamment `SUB-000`, `0005`, ainsi que les anciens codes conserves comme alias. Le test emploie un alias volontairement distinct du code public afin d'eviter toute ambiguite de classement. La correspondance exacte conserve sa priorite.

Validation : `npm run check`.
